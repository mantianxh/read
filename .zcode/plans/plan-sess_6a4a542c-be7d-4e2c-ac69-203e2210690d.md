## 静读站二期：目录/AJAX/排版/字体/灯箱/性能（本次不部署）

### 需求映射
| 需求 | 方案 |
|---|---|
| 一个换行就算空行 | markdown 加 `nl2br` 扩展，**全局开启**（已确认）。构建时先去掉行首全角空格再渲染 |
| 段落开头空两格 | 构建时 strip 行首 `\u3000`（西游记 3109 处，柳州 0 处），CSS `.prose p { text-indent: 2em }` 统一实现，不污染文本内容 |
| 字体 | layout 引入 `https://fontsapi.zeoseven.com/79/main/result.css`（Clear Han Serif，154 分片按 unicode-range 按需加载，font-display:swap）+ preconnect；font-family 栈首位加 `"Clear Han Serif"` |
| 章节页显示目录 + AJAX | 章节页放"目录"按钮 → 右侧滑出面板；构建时每书生成 `toc.json`，JS `fetch` 懒加载并渲染多级目录树（当前章高亮、可折叠） |
| 更多层目录（锚点，不破坏分章） | 分章逻辑不变（仍按 H1/H2）；章节内部 H2/H3 标题行注入 `{#sec-N}` id（中文默认 slug 生成空 id `_1`，必须显式注入），toc.json 记录 `chNNN.html#sec-N` 锚点。书目录页保留静态一级章节列表，点章节展开按需 AJAX 显示其 H2/H3 子项 |
| 图片灯箱 | 章节内图片加 `class="lightbox-img"`，点击弹全屏遮罩大图，支持左右切换（本章内）、ESC/箭头/点遮罩关闭 |
| 前端代码压缩 | `pip install rcssmin rjsmin`，构建时压缩 assets → `dist/assets/style.min.css` / `reader.min.js`，模板引用压缩版；HTML 做轻度空白清理 |
| 优化性能 | 图片 `loading="lazy"` + 从 GIF 头解析注入 `width/height` 防 CLS；toc.json 懒加载+内存缓存；字体分片按需加载+preconnect；CSS/JS 压缩 |
| 不推送热铁盒 | 本回合只构建 + 本地验证，不执行 deploy |

### 实施步骤
1. `pip install rcssmin rjsmin`
2. **build.py**：
   - markdown 扩展 `["extra", "nl2br"]`
   - 分章后每行 strip 行首 `\u3000`
   - 逐章扫描 H2/H3 → 改写标题行加 `{#sec-N}` + 收集 (层级, 标题, id)
   - 图片：复制时解析 GIF 头存 (w,h)；渲染后 `<img>` 后处理加 `class="lightbox-img" loading="lazy" width height`
   - 生成 `books/<id>/toc.json`（章节 + 每章 H2/H3 锚点）
   - 压缩 CSS/JS → `dist/assets/*.min.*`；轻度 HTML 清理
3. **模板**：layout 加字体 link/preconnect、灯箱 DOM、目录面板容器；chapter.html 加"目录"按钮+面板骨架、`data-book-id/data-current`；book.html 章节项加"展开子目录"按钮
4. **assets/style.css**：Clear Han Serif 字体栈、`text-indent:2em`、滑出面板样式、灯箱样式、目录树样式
5. **assets/reader.js**：加载/缓存 toc.json + 渲染目录树（章节页面板 + 目录页展开）、灯箱逻辑、保留字号/主题功能
6. 运行 build，本地 `python -m http.server` + curl 验证：nl2br 渲染、行首空格已去、text-indent、锚点 id 与 toc.json 一致、图片尺寸注入、字体 link、压缩产物、文件数 < 500
7. **不部署**、不做 git 操作（如需我再提交）
